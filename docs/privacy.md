# Politique de confidentialité — ntumba IA

## Données collectées

Selon le mode d'utilisation, ntumba IA peut collecter :
- e-mails ou identifiants d'utilisateur,
- informations de paiement via Stripe (dans la mesure où Stripe les gère),
- informations techniques de diagnostic,
- historique de conversation si le service le permet.

## Utilisation des données

Les données sont utilisées pour :
- fournir le service,
- vérifier les licences,
- gérer les abonnements,
- améliorer le produit,
- répondre aux demandes de support.

## Stockage

Les données sensibles doivent être stockées dans des environnements sécurisés, avec accès restreint.
Les clés API et les secrets ne doivent pas être commités dans le dépôt.

## Droits

L'utilisateur peut demander la suppression de ses données selon la législation applicable.

## Important

Ce document est un modèle de base. Il doit être ajusté et validé par un avocat selon le pays d'exploitation et les obligations légales applicables.
